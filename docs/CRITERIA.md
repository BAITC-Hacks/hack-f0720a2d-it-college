## Проверка запретов

| Правило | Подтверждение |
|---|---|
| Нет автоматического назначения | Новые отклики pending; только владелец меняет выбранный отклик; принятие двух команд не меняет другие |
| Низкий рейтинг не скрывается | Нет нижнего порога каталога/отклика; UI показывает «Требует уточнения». Порог 40 — только у рекомендаций |
| Публикация после ручного подтверждения | Требуется confirmed; правка перед публикацией сбрасывает его; устаревшая серверная версия отклоняется |
| AI не дописывает факты | Выход проверяется против дословного ввода/ответа того же поля, иначе повтор/502 без изменения карточки; смысл проверяет человек |
| Баллы только за подтверждённое заполнение | Снимок конкретных значений; новая/изменённая строка получает 0 до подтверждения; прогноз не влияет на каталог |

## Проверка синхронизации с AI-версией (23.09.2026)

Объединён `origin/main` (`a93a4f5`) и локальная OpenAI-compatible интеграция. Проверено **149 тестов**, одно прежнее предупреждение Starlette/AnyIO. Дополнительно прошли браузерные сценарии: 8 проверок раздельных кабинетов, 12 проверок удаления и полный сценарий с реальным LM Studio (`google/gemma-4-e4b`) от анализа/кэша/сборки до публикации, двух команд, результата и подтверждения правок. Проверены мобильный экран и отсутствие необработанных ошибок JavaScript. Проверки использовали отдельную засеянную SQLite; повторный seed не меняет записи.

Сохранены новые правила подтверждённого рейтинга и условной записи, локальные настройки AI, обнаружение моделей, приватность черновиков, предварительные правки опубликованных карточек и результаты обеих версий схемы. Короткая цитата модели восстанавливается до полного однозначного предложения источника, поэтому отрицания и ограничения не теряются. Кэш прежней политики проверки инвалидируется. Публичный llmster проверен на уровне HTTP-контракта, без реального внешнего адреса/ключа.
